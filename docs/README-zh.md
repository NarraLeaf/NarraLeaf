## 关于

NarraLeaf 是一款轻量级、高度可定制的视觉小说引擎，专为速度和开发者控制而设计。以最少的代码和最大的灵活性构建并打包跨平台视觉小说。

### 为什么选择 NarraLeaf？

- **更轻量** – 零渲染引擎，开销极小，针对大多数低端设备流畅运行进行了优化。
- **更快速** – 可定制的应用和内置自动化（如 CI 和代码检查）助你更高效地开发，减少繁琐工作。
- **更友好** – 标准化的前端开发体验，严格类型检查，无语言依赖
  - **TypeScript** – 以 TypeScript 为主要语言，完整支持类型检查和自动补全。

## 安装

$ npm install -g narraleaf
